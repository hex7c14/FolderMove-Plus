# FolderMove-Plus

> C 盘又红了？不用卸载重装，把软件搬到其他盘就行。

---

## 这东西干嘛的

Windows 用久了都懂——QQ、微信、Steam、各种 IDE 全往 C 盘塞，不知不觉就飘红。
常规操作是卸载了重装到 D 盘，麻烦不说，还可能丢配置、丢聊天记录。

**FolderMove-Plus** 用 Windows 自带的 NTFS 「目录联接」干了件巧事：
把软件的真实文件搬到 D 盘（或其他盘），然后在 C 盘原位置留一个"透明入口"。
对软件和系统来说，路径完全没变——该怎么跑还怎么跑，但 C 盘空间实打实腾出来了。

说白了就是：**文件走了，路还在。**

## 能干啥

- 自动扫出 C 盘装了啥（跟控制面板的列表是同一个来源，不会乱扫）
- 按风险等级标颜色，系统目录/驱动运行库会高亮提醒你慎碰
- 搬之前检测有没有进程占着文件，有的话列出来，确认后一键结束
- 所有操作都记着，哪天想搬回 C 盘了，点一下还原就行
- 自动申请管理员权限，不用你手动右键"以管理员身份运行"
- 暗色模式，跟系统走

## 怎么用

1. 打开软件（会弹 UAC 点同意）
2. 从列表里选要搬的软件，点「移动」
3. 选目标盘，等进度条走完

完事。在「已移动」标签页能看到历史，随时可以还原。

> ⚠️ 搬之前**把目标软件彻底退了**（包括托盘里的后台进程），不然文件被占着会搬失败。
> 标 🔴 高风险的那些，不是不能动，但动手前最好想清楚——尤其是驱动和运行库，别的软件可能指着它们活。

## 想自己编译

需要的东西：
- Windows 10 1809 以上（Win11 自带 WebView2，Win10 缺的话装一下就行）
- Rust 1.77+
- Node.js 18+
- Visual Studio 的 C++ 构建工具（MSVC）

然后：

```bash
pnpm install
pnpm tauri dev      # 开发模式，带热重载
pnpm tauri build    # 打包，产物在 src-tauri/target/release/
```

Release 开了 LTO + size opt，打出来的单文件 exe 也就几 MB，没运行时依赖。

## 技术这块（感兴趣就看）

- **Tauri 2 + Rust**：后端直接调 Win32 API，操作注册表、进程、文件系统都走原生
- **React + Tailwind**：前端界面，组件化，暗色模式用 `dark:` 前缀就搞定了
- **robocopy**：不是自己写文件复制，调系统自带的 robocopy（16 线程，保留权限/时间戳/ACL）
- **FSCTL_SET_REPARSE_POINT**：Junction 的创建走的是这个原生 IOCTL，不是 mklink 命令，可控性强
- **移动记录**：存在 JSON manifest 里，结构简单，删了也不影响已搬好的链接
